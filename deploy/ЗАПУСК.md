# Запуск AITRADING.KG: бот, сервер, домен

Что где работает:

| Часть | Где | Нужен сервер? |
|---|---|---|
| Сайт и приложение (PWA) | Cloudflare Pages, бесплатно | нет |
| ИИ-помощник, вход через BinoDex, уведомления | Cloudflare Functions | нет |
| Обновление данных и новостей | GitHub Actions, бесплатно | нет |
| **Telegram-бот** (регистрация, проверка ID, сигналы, админка) | **VPS-сервер** | **да**, бот должен работать круглосуточно |

Ключи (токен бота, BingX API, Anthropic) **никогда** не отправляйте в чат и не вставляйте в файлы сайта. Их вводите только туда, куда скажет инструкция.

---

## Шаг 1. Создать бота в Telegram (5 минут)
1. Откройте в Telegram **@BotFather** и выполните `/newbot`.
2. Имя бота: `AITRADING.KG`.
3. Логин должен заканчиваться на `bot`, например `aitrading_kg_bot`.
4. BotFather пришлёт **токен** вида `123456:AA…`. Сохраните его у себя и никому не показывайте.
5. Напишите мне **только логин** бота (без токена). Я поставлю ссылку на бота на сайт: кнопки «Telegram-бот» и регистрация начнут вести в бота.

## Шаг 2. Купить сервер (VPS)
Требования:
- система **Ubuntu 24.04**;
- 1 vCPU, 1–2 GB RAM, от 20 GB диска;
- расположение **Европа** (Германия, Финляндия, Нидерланды). **Не США**: Binance закрывает доступ с американских IP, а сигналы берут данные оттуда.

Где купить, на выбор:
- Hetzner Cloud (тариф CX22);
- DigitalOcean или Vultr (Basic).

Обычно это несколько долларов в месяц, точную цену смотрите на сайте провайдера. При создании выберите вход по паролю. Провайдер даст **IP-адрес** и **пароль root**.

## Шаг 3. Установить бота на сервер (10 минут)
1. Дважды нажмите `Сайт_AITRADING_kg\Сервер_орнотуу.bat` и введите IP сервера.
2. Первый вопрос — напишите `yes`. Потом пароль root (при вводе он не виден, это нормально).
3. Установщик покажет **ключ GitHub** (строка `ssh-ed25519 …`):
   - откройте ссылку, которую он напишет (GitHub → Settings → Deploy keys → Add);
   - Title: `aitrading-server`, вставьте ключ;
   - галочку «Allow write access» **не ставьте**;
   - нажмите Add key, вернитесь в окно установщика и нажмите Enter.
4. Установщик спросит **токен бота**. Вставьте его правой кнопкой мыши и нажмите Enter (на экране он не виден).
5. Откройте своего бота в Telegram, нажмите **Start** и нажмите Enter в установщике. Ваш чат станет **админским**.
6. **BingX API** (можно пропустить кнопкой Enter, подробнее в шаге 4).
7. **BinoDex OAuth** — пока пропустите кнопкой Enter.
8. В конце появится «Даяр! Бот иштеп жатат».

После установки бот:
- перезапускается сам после сбоя и после перезагрузки сервера;
- каждые 10 минут сам берёт новый код из GitHub.

Команды на сервере (войти можно так: `ssh root@IP`):
- `aitrading status` — работает ли бот;
- `aitrading logs` — журнал;
- `aitrading restart` — перезапуск;
- `aitrading setup` — заново ввести токен или ключи.

## Шаг 4. BingX API — автоматическая проверка ID
Без ключа бот тоже работает, но ID с BingX тогда подтверждает админ кнопками ✅/❌.

Если нужна автоматическая проверка:
1. Войдите в **основной партнёрский (агентский)** аккаунт BingX.
2. Профиль → API Management → Create API.
3. Права: **только Read (чтение)**. Trade и Withdraw **не включать**.
4. IP restriction: **IP вашего сервера**.
5. На сервере выполните `aitrading setup` и вставьте API Key и Secret Key (на экране они не видны).

## Шаг 5. Домен ai-trading.kg
На 24.11.2026 свободны оба адреса: `ai-trading.kg` и `aitrading.kg`. Можно взять оба: второй будет перекидывать на первый, если человек наберёт адрес без дефиса.
1. Зарегистрируйте домен в официальном реестре: https://www.cctld.kg.
2. Cloudflare → **Add a domain** → `ai-trading.kg` → тариф **Free**. Cloudflare покажет 2 адреса **nameservers**.
3. В кабинете cctld.kg, в настройках домена, укажите эти 2 nameserver (DNS-серверы). Применение занимает от нескольких минут до 24 часов.
4. Cloudflare → Workers & Pages → `aitrading-kg` → **Custom domains** → `ai-trading.kg` (и `www.ai-trading.kg`).
5. Напишите мне «домен работает». Я переключу адреса в сайте и боте (`SITE_URL`, ссылки) и скажу, какой адрес возврата поменять в кабинете BinoDex.

## Шаг 6. Ключ Claude (ИИ-помощник и переводы новостей)
1. Создайте ключ на https://console.anthropic.com (API Keys). В разделе **Limits** поставьте месячный лимит расходов.
2. Добавьте его в Cloudflare: Pages → `aitrading-kg` → Settings → Variables and Secrets → `ANTHROPIC_API_KEY` (Secret). Это для ИИ-помощника.
3. Добавьте его в GitHub: репозиторий → Settings → Secrets and variables → Actions → `ANTHROPIC_API_KEY`. Это для переводов новостей и ИИ-обзоров.

### Как пользователь проходит путь
1. Сайт → «Катталуу» → выбирает BingX или BinoDex → регистрируется по нашей ссылке (BinoDex: код `traderkg`).
2. Переходит в бота → отправляет ID брокера.
3. Бот проверяет ID: BingX — автоматически по API, BinoDex — подтверждает админ.
4. После проверки бот открывает ⭐ сигналы. Если 40 дней не заходить в бота, доступ приостанавливается.
